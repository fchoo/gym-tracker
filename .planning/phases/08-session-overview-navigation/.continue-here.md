## Clean-commit pattern (copy exactly)

```
MSG="type(scope): subject

Body.

Co-authored-by: TRAE CLI <noreply@users.noreply.github.com>"
git add -A
TREE=$(git write-tree)
PARENT=$(git rev-parse HEAD)
NEWC=$(printf '%s' "$MSG" | git commit-tree "$TREE" -p "$PARENT")
git update-ref HEAD "$NEWC"
git reset -q --mixed HEAD
git log -1 --format=%B | grep -c Co-authored-by   # must print 1
```
