<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| application command → SQLite writer | Untrusted timing/repeated calls cross into authoritative source mutation. |
| writer → separate reader | Readers must see committed state only. |
| development-test runner → production adapter | Test seams must exercise real behavior without escaping into release. |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-04-01 | Tampering | transaction executor | mitigate | FIFO ownership, BEGIN IMMEDIATE, bound parameters, revisions/idempotency, and rollback injection. |
| T-01-04-02 | Repudiation | commit acknowledgement | mitigate | Commit latch and APK-hash-bound device result artifact. |
| T-01-04-03 | Denial of Service | write contention/resources | mitigate | Bounded timeout, short transactions, finalized statements, and repeated leak suite. |
| T-01-04-04 | Elevation of Privilege | raw writer/test route | mitigate | Static import boundary and build-profile exclusion. |
| T-01-04-SC | Tampering | npm installs | mitigate | No new packages; use Expo SQLite and Node built-in SQLite from the approved lockfile. |
</threat_model>
