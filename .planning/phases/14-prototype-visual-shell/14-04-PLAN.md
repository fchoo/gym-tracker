<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Background screen -> modal overlay | Background actions must become inert while untrusted keyboard/touch/accessibility input targets a modal. |
| Authoritative command result -> toast host | Presentation may announce a result but must not manufacture or advance source state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-14-11 | Tampering | BottomSheet background | high | mitigate | Explicit focus containment, modal accessibility isolation, inert pointer/keyboard background, and common no-write dismissal tests. |
| T-14-12 | Spoofing | SemanticToast | high | mitigate | Enqueue success only from authoritative post-result callers; keep errors/retry inline and test that timers never update domain state. |
| T-14-13 | Denial of Service | ConfirmationDialog | medium | mitigate | Latch/busy-disable competing submit and preserve caller-owned idempotency/preflight guards. |
| T-14-14 | Information Disclosure | Toast copy | medium | mitigate | Accept bounded user-facing messages only and test absence of raw errors, paths, tokens and account identifiers. |
</threat_model>
