## Reading the matrix

- `E` = existing source path; `P` = proposed addition, not a file created by this planning task.
- `prototype_source` = current source contains an entry/handler; independent rendered/native verification still required.
- `prototype_present_unwired` = visible source intent without real navigation/persistence.
- `required_native` = preserved shipped or owner-required failure/recovery/empty behavior not fully demonstrated in the prototype.
- `required_domain` = source integrity prerequisite, not a visual route.
- `H:L` = approved-hybrid.html line L; full source paths and exact selectors are in JSON.
- Each row plans both a concrete behavioral check and an evidence path. None records a test as passed.
- DEV-01/DEV-02 are proposed accessibility adaptations, not accepted changes; refer to [deviation register](v1.2-DEVIATIONS.md) for the current owner decision. The matrix does not approve them.
