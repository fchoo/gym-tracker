## Standalone application

The owner wants an installed standalone app. Runtime operation must not require
Trae, GSD, Codex, Claude, an LLM, an AI agent, a development terminal, a Metro
server, or a desktop helper unless the owner separately selects the desktop
bridge architecture. Bundled ordinary JavaScript/Python/native code is allowed
as a proposed architecture; it is not dynamically invoked AI.

Hermes is React Native's embedded JavaScript engine. There is no owner-selected
requirement to adopt or switch to a particular JavaScript engine. Retain the
framework-supported runtime unless a separate technical reason requires a
change. If Python is selected, it is packaged inside the APK and called through
native methods; no on-device pip installation or remote script/agent loading.

  official API credentials, program approval, or a broker are available.

  the owner's own Garmin data. This expressly authorizes investigating the
  unofficial account-login route despite the earlier planning exclusion.
- Compare self-contained Android execution with a desktop background helper
  exporting to Google Drive for the phone to import. Neither architecture is
  selected for implementation merely by this exploration request.
- Explore the JSON activity endpoints first. FIT decoder selection, adoption,
  and its previous special license/Hermes gates are deferred until the transport
  and required data fidelity are settled.
- Do not require a paid software licence or Garmin program licence for an MIT
  library. Preserve applicable open-source notices as ordinary packaging work;
  do not turn them into another owner-approval ceremony.
