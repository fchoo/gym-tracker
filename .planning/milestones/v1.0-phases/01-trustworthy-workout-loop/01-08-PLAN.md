## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| repeated UI/external input → completeSet | Duplicate or stale commands could double-write. |
| SQLite commit → haptic/UI/effects | Premature acknowledgement could lie about persistence. |
| editable values → bound SQL | Numeric input must be validated and parameterized. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-01-08-02 | Repudiation | commit acknowledgement | mitigate | Commit latch and post-commit-only probes/UI. |
| T-01-08-03 | Tampering | Undo | mitigate | Injected clock, serialized prior state, expiry/revision transaction. |
| T-01-08-04 | Denial of Service | rapid activation | mitigate | Idempotent current-state result and busy UI without relying on UI lock. |
| T-01-08-SC | Tampering | package installs | mitigate | No new packages. |
</threat_model>
