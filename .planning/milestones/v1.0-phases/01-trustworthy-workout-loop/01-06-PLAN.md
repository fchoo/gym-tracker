<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| retained database → new schema | Existing owner data crosses migration code. |
| committed effect row → external/derived handler | At-least-once work must not duplicate or act on stale facts. |
| launch coordinator → enabled UI | UI must not read or mutate untrusted/partially migrated state. |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-06-01 | Tampering | migrations | mitigate | Proven writer, ordered manifest, fixture/failure injection, transactional user_version, integrity checks. |
| T-01-06-02 | Denial of Service | effect runner | mitigate | Leases, stale reset, bounded batch/retry, safe permanent failure. |
| T-01-06-03 | Repudiation | effect execution | mitigate | Stable IDs/idempotency keys/source revisions and safe status/error fields. |
| T-01-06-04 | Information Disclosure | recovery/error UI | mitigate | Internal no-backup storage and redacted correlation-only diagnostics. |
| T-01-06-SC | Tampering | package installs | mitigate | No new packages; use approved Expo SQLite APIs. |
